音声認識：判定中…
判定のしくみ
ブラウザの音声認識に英語として聞かせ、意図した語として聞き取られたかを見ます。 発音の良し悪しを音響的に採点しているのではなく、「通じたかどうか」を見ています。
認識結果が狙いの語と一致すれば ◎、候補（第2〜5候補）に入っていれば △、 あらかじめ登録した誤認されやすい語になっていれば ✗ として、何が起きたかを表示します。
認識にはネット接続が要ります。 また静かな場所のほうが安定します。
貼り付ける JSON の形 
{
  "focus": "vowel-er",
  "items": [{
    "word": "batter",
    "ipa": "/ˈbætər/",
    "types": ["vowel-er","r-l"],
    "confused": ["battle"],
    "tip": "語末で舌先をどこにも触れさせない。",
    "sentence": "The batter hit a foul tip."
  }]
}
word 以外は省略できます。confused は「誤認されやすい語」。
